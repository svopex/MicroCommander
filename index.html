Co umí

Dva panely jako v Salamanderu

Kurzor oddělený od označení, řádek „..“, rychlé hledání psaním, historie, režimy Stručný / Podrobný / Ikony / Miniatury / Dlaždice / Typy a lišta F-kláves, jejíž popisky se mění podle držených modifikátorů.

Souborové operace

Kopírování, přesun a mazání mezi libovolnými zdroji se zrušením a průběhem, koš i trvalé mazání, duplikace, porovnání adresářů, obsazené místo, atributy a vlastní dialog oprávnění včetně rekurze.

Archivy

ZIP, TAR a TAR.GZ se otevírají jako adresář v panelu. Vytváření ZIP včetně šifrování AES-256 nebo ZipCrypto, čtení zaheslovaných archivů.

FTP a SFTP

Uložené servery s hesly v Klíčence, SFTP přihlášení heslem, klíčem (ed25519, ECDSA, RSA) i přes ssh-agent. Panel lze procházet i během přenosu.

Hledání

Masky ve stylu Salamandera (*, ?, #, skupiny ;, vyloučení |), hledání v obsahu – text, HEX, celá slova, regulární výrazy – a volitelně i uvnitř archivů.

Vestavěný terminál

Shell uživatele pod panely (SwiftTerm), který sleduje adresář aktivního panelu; ⌘F12 ho roztáhne na celé okno. Spouštění skriptů přímo z panelu.

Nastavení po svém

Editor klávesových zkratek všech příkazů, barevná schémata (macOS, Open Salamander, Norton Commander, DOS Navigator…), vlastní místa v nabídce disků se zkratkami ⌘0–⌘9, export nastavení do JSON.

Nativní Mac aplikace

Přetahování souborů z a do Finderu, Quick Look náhledy, okno Informace z Finderu, víc oken, světlý i tmavý režim.

Architektura

app/ – Swift/AppKit

Tenké UI: panely, příkazy, dialogy, terminál. Volá jádro přes C ABI.

C ABI · microcommander.h

core/ – salcore (Rust)

Veškerá logika: virtuální souborové systémy (lokální disk, ZIP, TAR, FTP, SFTP) za společným traitem Vfs, operace, hledání, balení archivů.

Sestavení a spuštění

Vyžaduje Rust (cargo) a Xcode Command Line Tools (swiftc).

git clone https://github.com/svopex/MicroCommander.git
cd MicroCommander
make run        # sestaví jádro i aplikaci a spustí build/MicroCommander.app

Další cíle: make test (unit testy jádra), make smoke (test FFI), make selftest (self-test UI). Podrobnosti v README.
