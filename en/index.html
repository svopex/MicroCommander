Features

Features you know from Salamander

Two panels, just like Salamander

A cursor separate from the selection, quick search by typing, history, six view modes and an F-key bar that changes with the modifier keys.

File operations

Copy, move and delete between any sources with progress and cancel, Trash, duplicate, directory compare, attributes and permissions.

Archives

ZIP, TAR and TAR.GZ open like a folder. Create ZIP files with AES-256 or ZipCrypto encryption and read password-protected archives.

FTP and SFTP

Saved servers with passwords in the Keychain, sign-in with a password, a key (ed25519, ECDSA, RSA) or ssh-agent; keep browsing during transfers.

Search like in Salamander

Salamander-style masks and content search – text, HEX, whole words, regular expressions – optionally even inside archives.

Built-in terminal

A shell below the panels that follows the active panel's folder. ⌘F12 expands it to the whole window, and scripts run straight from the panel.

Make it yours

Custom keyboard shortcuts for every command, color schemes (Open Salamander, Norton Commander, DOS Navigator…) and settings export.

A native Mac app

Drag and drop to and from Finder, Quick Look previews, the Get Info window, multiple windows, light and dark mode.

For Salamander users

Switching from Altap Salamander to a Mac?

MicroCommander works like Salamander on Windows, so most of your habits carry over unchanged.

Keyboard shortcuts like in Altap Salamander

F3 view, F4 edit, F5 copy, F6 move, F7 new folder, F8 delete, ⌥F5 pack into ZIP. Ctrl shortcuts also have a ⌘ variant on the Mac, and every one can be remapped in Settings.

Panels and selection like in Salamander

A cursor separate from the selection, selected items in red, Space and Insert to select, Num + / Num − by mask, ⌃H for hidden files and quick search by typing.

Colors from Open Salamander

Besides the macOS look (light and dark), it offers the Open Salamander, Windows Explorer, Norton Commander and DOS Navigator color schemes.

What is still missing

Plugins, 7z and RAR formats, and FTPS. Archives are read-only – but you can create new ZIP files. On a Mac keyboard the F-keys need Fn.

FAQ

Salamander for Mac – questions and answers

Is there an Altap Salamander for Mac?

Altap Salamander is a file manager for Windows and there is no official macOS version. MicroCommander is an independent dual-pane file manager for macOS that adopts Salamander's controls. It is a port of Open Salamander, not an official Altap product.

What is the difference between Altap Salamander, Open Salamander and MicroCommander?

Altap Salamander is the original dual-pane file manager for Windows made by Altap. Open Salamander is its open-source version, released under the GPL. MicroCommander is a new rewrite for macOS with a Rust core and a Swift/AppKit interface; it uses the source code of Open Samandarin, a community fork of Open Salamander, as its behavior reference. It is not affiliated with Altap.

Does it use the same keyboard shortcuts as Salamander?

Yes, the controls follow Salamander: F2 rename, F3 view, F4 edit, F5 copy, F6 move, F7 new folder, F8 delete, Alt+F5 pack into ZIP and Ctrl+F3 to Ctrl+F6 to sort. Ctrl shortcuts also have a ⌘ variant on the Mac. On a Mac keyboard the F-keys need Fn, or turn on “Use F1, F2, etc. keys as standard function keys”. Every shortcut can be changed in Settings, and F1 shows an overview.

Does it support FTP, SFTP and archives like Salamander?

Yes. FTP and SFTP with saved servers and passwords in the Keychain; SFTP sign-in with a password, a key (ed25519, ECDSA, RSA) or ssh-agent. ZIP, TAR and TAR.GZ open like a folder, and you can create ZIP files, including AES-256 or ZipCrypto encryption. Archives are read-only for now; 7z, RAR and FTPS are not supported.

Is MicroCommander free?

Yes, completely free, with no ads, accounts or telemetry. It is free software licensed under GPL-2.0-or-later, with its source code on GitHub.

Does it run on Apple Silicon and Intel Macs?

MicroCommander requires macOS 13 or later and is built right on your Mac for its processor. It is developed and tested on Apple Silicon; building on an Intel Mac has not been verified yet.

How do I install MicroCommander?

There is no prebuilt app to download yet. MicroCommander is built from source with three commands in Terminal; you need the Xcode Command Line Tools and Rust. Then drag the resulting build/MicroCommander.app to your Applications folder.

Download

Up and running in three steps

The app is built right on your Mac – just open Terminal and paste these commands one at a time.

  1. Build tools first time only

    Xcode Command Line Tools (the Swift compiler) and Rust.

    xcode-select --install
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y

  2. Download the source code

    The latest version as an archive, no git needed.

    curl -L https://github.com/svopex/MicroCommander/archive/refs/heads/main.tar.gz | tar xz
cd MicroCommander-main

  3. Build and run

    The finished app is in build/MicroCommander.app – drag it to your Applications folder.

    make run

To get a new version, repeat steps 2 and 3. Other targets (make test, make selftest) are described in the README.
